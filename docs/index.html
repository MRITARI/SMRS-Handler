SMRS-Handler

Simple Multi Reverse Shell Handler

Overview

A light, console-based reverse-shell manager and interactive listener written in Python 3. It allows you to accept and manage multiple reverse shell connections, select a client, and interact with it from a single terminal.

Features

  • Multi-client TCP support
  • Auto-assigned client IDs
  • Interactive console
  • Per-client output handling
  • Integrated shell one-liners

Requirements

  • Python 3.8+
  • pip install colorama pygments

Workflow

1. Start listener: python3 smrs.py

2. Execute reverse shell payload on target.

3. Use list to view connections.

4. Use use <id> to interact.
